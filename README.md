# Rare Fish Finder

Client-side Fabric mod that makes rare tropical fish easy to spot. Vanilla
spawns the same 22 common varieties most of the time, everything else is rare
and this mod makes those glow and shows their pattern and colors above them.

## Usage

- Rare fish glow (R to toggle) and get a name tag with their variant (N to toggle)
- Glow color and everything else is in Mod Menu > Rare Fish Finder

If you run Xaero's Minimap there are two extra options, both off by default:
hide common fish from the minimap and world map, or hide everything except
tropical fish so the map only shows what you are hunting.

## Requirements

Minecraft 26.1+, Fabric API and Cloth Config. Mod Menu recommended, Xaero's
Minimap optional.
